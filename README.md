# Hivora F&B · AI 营销团队 Demo

Warisan Grill 的 AI 营销团队产品演示（静态页面，无后端）。

**演示地址**：https://xxxintangxx1027.github.io/hivora-fnb-demo/

## 内容
- 💬 店长助理：对话式入口，可上传销售表 / 菜单 / 照片，含对话历史
- 🏢 Agent Floor：像素办公室，实时看四个 agent 在干嘛；可编辑 SOUL / MEMORY / TOOLS / MCP / SKILLS
- 📊 Weekly Report：菜品四象限（销量 × 毛利）+ 人潮热力
- 🎯 Promotion Plans / 🖨️ Material Review：促销方案 → 物料 → **确认 / 改 / 退**
- 🕌 Race Rule Gate：族群铁律代码级拦截（牛肉不投印度裔 / 素食）
- 📅 Marketing Calendar：排期与印刷倒数

> 演示数据为模拟数据，非真实营业数据。节假日为示例日期。

💼 为什么通用 AI 工具做不了本地 F&B
他们不知道屠妖节要避牛肉，也没有地方放这条规则。在我们这里，它是流水线上的一个节点，用 Python 写死 —— 提示词会被无视，代码不会。 
def race_gate(target_group, items):
    beef = [i for i in items if 含牛肉(i)]
    if beef and target_group in {"indian", "vegetarian"}:
        return {"passed": False,
                "reason": f"🚫 铁律：牛肉物料 {beef} 不投 {target_group}"}
    return {"passed": True}
Gate 不过 → 自动回上游重出，最多 3 次；仍不过就标 blocked 上报，不会无限循环，也不会绕过。
